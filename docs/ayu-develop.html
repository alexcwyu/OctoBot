Design decisions

Decision Rationale Tradeoff Evidence
Initialize evaluators before exchange/service producers. Evaluator subscriptions and feed requirements must exist before feeds run. Startup relies on ordered asynchronous package lifecycle. OctoBot.start_producers (L144)
Enumerate evaluator/timeframe/risk configuration combinations. Compare configuration outcomes under copied strategy test-suite settings. Search size grows with technical evaluator and timeframe combinations; configuration optimizer is not a universal ML or distributed optimization platform. StrategyOptimizer.find_optimal_configuration (L87) / StrategyOptimizer._run_test_suite (L185)

Strengths and limits

Strengths

  • Explicit evaluator → exchange → feed → interface startup order records actual runtime dependencies. OctoBot.start_producers (L144)

Limitations

  • A host install and activated tentacles determine exchange, strategy and UI availability. ExchangeProducer.create_exchange (L86) / InterfaceProducer.start_interfaces (L50)
